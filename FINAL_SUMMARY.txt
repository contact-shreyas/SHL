📊 SOLUTION ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════

TECH STACK:
  • Backend: FastAPI (async Python)
  • Retrieval: FAISS + sentence-transformers (all-MiniLM-L6-v2)
  • LLM: Gemini 1.5 Flash (primary), Groq (fallback)
  • Deployment: Render (free tier)
  • Data: ~400 SHL assessments in FAISS vector index

REQUEST FLOW:
  1. User sends POST /chat with conversation history
  2. System extracts last 3 user turns as retrieval query
  3. Sentence-transformer encodes query to vector
  4. FAISS returns top-20 most similar assessments
  5. Top-20 catalog data injected into LLM context
  6. LLM generates response + recommendations
  7. URL validation: only allow catalog URLs
  8. Schema validation: Pydantic checks response
  9. Return JSON to client

CONVERSATIONAL BEHAVIOR:
  • Turn 1 + vague: Ask clarifying questions, no recommendations
  • With context: Return 1-10 relevant assessments
  • Mid-conversation edit: Re-retrieve and update shortlist
  • Off-topic: Refuse politely, no recommendations
  • Prompt injection: Ignore, stay on task

💡 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Q: Deployment fails?
A: Check Render dashboard logs. Most common: GEMINI_API_KEY not set.
   Make sure you've added it to Environment Variables in Render.

Q: /health returns 502?
A: Service is still starting (3-5 min). Wait and retry.
   Or check "Logs" tab in Render dashboard.

Q: /chat returns empty recommendations?
A: This is CORRECT for vague queries (first turn).
   Try with more specific query: "Senior Java developer..."

Q: Response takes 30+ seconds?
A: This is cold-start (service woke from sleep).
   Subsequent requests will be <1 second.
