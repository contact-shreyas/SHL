DEPLOYMENT TO RENDER (Free Tier)
═══════════════════════════════════════════════════════════════════════════

STEP 1: Get LLM API Keys (Required)
  ────────────────────────────────
  
  Option A - Use Gemini (Recommended - FREE):
    1. Go to: https://aistudio.google.com
    2. Click "Get API Key"
    3. Click "Create API Key in new project"
    4. Copy the key
    
  Option B - Use Groq (Fallback - FREE):
    1. Go to: https://console.groq.com/keys
    2. Sign up with email/GitHub
    3. Copy the API key

STEP 2: Deploy on Render
  ────────────────────────
  
  1. Go to: https://render.com
  2. Sign up (or log in if you have account)
  3. Click "New +" button → Select "Web Service"
  4. Connect GitHub repo:
     - Search for: "SHL" or "contact-shreyas/SHL"
     - Click "Connect"
  5. Fill in deployment form:
     - Name: shl-recommender
     - Environment: Python 3
     - Build Command: (auto-detected from render.yaml)
     - Start Command: (auto-detected from Procfile)
  6. Add Environment Variables:
     - Key: GEMINI_API_KEY
       Value: [paste your Gemini key from Step 1]
     - Key: GROQ_API_KEY
       Value: [optional - paste Groq key]
  7. Click "Create Web Service"
  8. WAIT 3-5 MINUTES for build and deployment

STEP 3: Get Your Public URL
  ──────────────────────────
  Once deployed, Render will assign a URL like:
    https://shl-recommender.onrender.com
  
  This URL will have both endpoints:
    • GET  /health
    • POST /chat

COLD START BEHAVIOR
═══════════════════════════════════════════════════════════════════════════

Render Free Tier Auto-Sleep:
  • After 15 minutes of inactivity: service spins down
  • First request after inactivity: 30-60 seconds delay
  • Subsequent requests: <1 second response time

This is expected behavior. To minimize cold starts in production, upgrade
to Render's paid tier ($7/month).

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

If /health returns error:
  → Check that deployment completed (should show "Live" in Render dashboard)
  → View logs in Render: Dashboard → Logs tab

If /chat returns error:
  → Verify GEMINI_API_KEY is set in Render Environment Variables
  → Check that API key is valid (test at: https://aistudio.google.com)
  → If Gemini fails, system will fall back to Groq (if key available)
  → If both fail, mock LLM returns reasonable responses (for testing)

If build fails:
  → Check build logs in Render dashboard
  → Verify all packages in requirements.txt are valid
